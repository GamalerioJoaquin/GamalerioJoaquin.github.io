# Joaquin Ignacio Gamalerio — Portfolio

Personal portfolio focused on applied AI, computer vision, biometric security, face anti-spoofing, deep learning, and software engineering.

## Structure

```text
.
├── _config.yml
├── index.html
└── assets
    ├── css/style.css
    ├── js/main.js
    ├── img/profile.jpeg
    └── docs/
```

## Publish with GitHub Pages

1. Copy these files to the root of `GamalerioJoaquin.github.io`.
2. Keep the profile image at `assets/img/profile.jpeg`.
3. Commit and push to the repository's default branch.
4. In GitHub, open **Settings → Pages** and publish from that branch if Pages is not already enabled.

The site uses a custom responsive layout and does not depend on a Jekyll theme.
